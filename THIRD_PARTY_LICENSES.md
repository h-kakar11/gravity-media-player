# Third-party licences

Gravity is built on open-source software. This file lists what ships inside the app and the terms it comes with. Regenerate it with `npm run licenses`.

## Platform and tools

- **Electron** (MIT) and **Chromium** (BSD-3-Clause and others). Electron’s own distribution carries `LICENSE` and `LICENSES.chromium.html` with the complete Chromium and Node.js notices; they ship alongside the application binary.
- **Node.js** (MIT) is embedded in Electron.
- **SQLite** (public domain) is embedded in Node.js and used through `node:sqlite`.
- **Inter** typeface by Rasmus Andersson — SIL Open Font License 1.1 (text below under `@fontsource-variable/inter`).
- **ffmpeg / ffprobe** are *separate programs*, started as child processes — Gravity does not link against them. The build in `@ffmpeg-installer/ffmpeg` is a static GPL-licensed build; its source is available from https://ffmpeg.org/ and from the packagers listed below. You can replace it with your own build in Settings → Performance → ffmpeg, or remove it and rely on a system installation. Gravity’s own code is not a derivative work of ffmpeg.
- **libvips** (LGPL-3.0-or-later) is the image library inside `sharp`. It ships as a separate shared library (`@img/sharp-libvips-*`) next to the app rather than being statically linked, so it can be replaced with another build of the same version.
